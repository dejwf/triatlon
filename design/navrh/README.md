# Návrh UI — zdrojové soubory

Artboardy z interaktivního návrhu (https://claude.ai/artifact/S8qBcijhaBv6Qkw8EiCocy).
Popis a zásady: [`design_claude.md`](../../design_claude.md).

| Soubor | Obrazovka |
|---|---|
| `Main.dc.html` | Veřejná tabule – web |
| `Kiosk.dc.html` | Veřejná tabule – kiosk / TV 1920×1080 (s QR kódem) |
| `Admin.dc.html` | Back-office – živý přehled závodu |
| `MobileGrid.dc.html` | Appka – checkpoint (záznam) |
| `MobileSync.dc.html` | Appka – bez signálu / synchronizace |
| `MobileResults.dc.html` | Appka – průběžné výsledky |

Formát `.dc.html` potřebuje runtime návrhového plátna; soubory slouží jako předloha
(rozložení, barvy, data), ne jako kód k přímému použití.
